# java-crud-api-rest
Realicé unAPI REST con operaciones CRUD desarrollada en Java con Spring Boot, Hibernate (Spring Data JPA) y PostgreSQL. Esta versión del proyecto java-crud-api-rest incluye la configuración necesaria para contenerizarla con Docker y desplegarla en Railway.

## Tecnologías

| Componente | Detalle |
|---|---|
| Lenguaje | Java 21 |
| Framework | Spring Boot 4.1.1 (`spring-boot-starter-webmvc`) |
| Persistencia | Spring Data JPA + Hibernate |
| Base de datos | PostgreSQL 17 |
| Build | Maven (Maven Wrapper incluido) |
| Contenedores | Docker (build multi-etapa) y Docker Compose |
| Despliegue | Railway |
